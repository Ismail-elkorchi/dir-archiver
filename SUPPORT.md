# Support

Start with the [documentation](docs/index.md) and
[troubleshooting guide](docs/troubleshooting.md).

For a usage question or bug, open a GitHub issue with:

- a minimal, non-sensitive reproduction;
- the `dir-archiver`, runtime, and operating-system versions;
- the API call or exact CLI command;
- the archive format, expected result, and actual result;
- the complete error code or CLI output.

Do not attach confidential archives. Reproduce the problem with the smallest
safe fixture possible.

Report vulnerabilities privately as described in
[SECURITY.md](SECURITY.md).
